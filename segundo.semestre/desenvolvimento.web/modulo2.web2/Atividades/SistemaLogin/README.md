# Sistema de Login e Cadastro em PHP

Este projeto é um sistema simples de login e cadastro feito em **PHP**, com **HTML e CSS**.

---

## Funcionalidades

- Página home
- Página de login  
- Página de cadastro  
- Validação de usuário  
- Salva dados num arquivo de txt
